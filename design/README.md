# Gustavi rada design prototype

A clickable version of the client's lo-fi wireframes (`reference/lofi-wireframes.webp`) for the Rahvaraamat loyalty program.

Open `index.html` in a browser. There is no build step and there are no dependencies.

- `#/` shows all screens as a board. `#/rada`, `#/tasu` and so on open one screen.
- `styles.css` starts with the design tokens. Change those when the brand palette arrives.
- `app.js` starts with the sample data. Change `member.points` and the cat, rail, bubble and stats all follow.
- `[BRACKETED]` text and dashed boxes are placeholders kept from the wireframes.
- Buttons with no destination in the wireframes (pay, wallet, share, QR) show a "not in the prototype yet" message.
